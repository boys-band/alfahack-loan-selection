# Ревью PR №1: decision

Дата: 24.10.2026. Исходная реализация: `abf2bd3f0f2fcc4fc89cc529ae32a82aa1045717`; исправления: `7999b6587f6dd63a918af7c244c61a3cf687c037`.

## Исправления

- **P2 — Java 17 вместо Java 21.** Toolchain и bytecode переведены на 21, Docker собирает сервис Wrapper-командой на JDK 21 и запускает на JRE 21. Образы закреплены digest. Обновлены Docker-контекст, документация и notices.
- **P2 — неполный dependency lock.** Сборка из Maven Central останавливалась на отсутствующем в lock-файле Jackson BOM. Lock пересоздан с BOM Jackson/JUnit; версии библиотек сохранены. Wrapper закрепляет Gradle 8.14.3 и SHA-256 дистрибутива.
- **P2 — потеря точности JSON и конфликт равных целых.** Дробные деньги могли округлиться через double и пройти как целые; версии `1` и `1.0` давали разные отпечатки/снимки. Числа разбираются точно, проверяются до преобразования в long и нормализуются перед записью. Переполнение bigint дает 422. Два новых HTTP/PostgreSQL-теста воспроизвели ошибки до исправления и прошли после него.
