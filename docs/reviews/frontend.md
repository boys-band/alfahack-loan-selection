# Ревью codex/frontend

Дата: 24.10.2026. Исходная реализация: `0428257fe8a73bf53986747a633568c0d1360f90`. Проверены production-код, HTTP/DTO, сессионный журнал, доступ, формы/документ, обновление состояния, тесты и контейнер.

## Исправления перед слиянием

- **P1 — отмена и retry блокировались после 202.** Принятая команда оставалась в журнале до завершения обработки и блокировала любые новые команды. После перехода worker в PAUSED клиент не мог выполнить RETRY_PROCESSING; отмена во время обработки также была отключена. Подтвержденную 202-команду теперь разрешено заменить отменой или повтором, если актуальный серверный ответ разрешает действие. Неизвестный исход, 412 и другие неразрешенные команды сохраняют блокировку и прежний ключ. Добавлены две проверки журнала и два браузерных сценария, включая PAUSED после submit и reload.
- **P2 — 401 при восстановлении команды не завершал сессию.** CommandBanner показывал ошибку вместо перехода на демовход. Восстановление и подтверждение конфликта теперь используют общую обработку неавторизованного ответа; добавлен браузерный сценарий 401 при повторе потерянной команды.

Изменения: [журнал](../../frontend/src/core/commands.ts), [действия](../../frontend/src/pages/application.tsx), [восстановление](../../frontend/src/components/commands.tsx), [регрессионные тесты](../../frontend/tests/commands.test.ts), [браузерные сценарии](../../frontend/e2e/cabinet.spec.ts).

## Проверка

- 25 unit/component/HTTP-тестов и 28 браузерных сценариев Chrome.
- TypeScript и production Vite build.
- Docker build из контекста `frontend/`; проверка одного образа с MOCK_API=false/true: runtime config, nested URL/reload, 404 assets, отсутствие ошибок браузера и отсутствие активных моков в real mode.
- Контракты: шесть OpenAPI, 54 операции, 81 HTTP-пример и восемь отрицательных примеров; исходные контракты не менялись.
- Desktop 1280×720 и 1440×900: клавиатура, диалог, отсутствие горизонтального переполнения и просмотр снимков.

После исправлений блокирующих замечаний не осталось. У сборки есть предупреждение о chunks больше 500 kB; моки загружаются отдельным chunk. Настоящая сквозная интеграция с backend/gateway не проверялась: бизнес-сценарии выполнялись с контрактными HTTP-стабами. В real mode проверена поставка frontend и отключение моков.
